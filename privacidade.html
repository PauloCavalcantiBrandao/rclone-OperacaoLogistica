Política de Privacidade

rclone OperacaoLogistica · vigente a partir de 13/10/2026

1. A quem se aplica

Este aplicativo OAuth é usado exclusivamente pelo responsável pela Operação Logística, em sua própria conta Google, para a rotina de cópia de segurança descrita na página inicial. Não há outros usuários, cadastro ou oferta ao público.

2. Dados do Google acessados

  • A autorização solicita o escopo https://www.googleapis.com/auth/drive, que permite ver, criar, alterar e excluir arquivos no Google Drive da conta autorizada.
  • A rotina de backup é configurada para usar apenas a pasta e os arquivos destinados aos backups: listar, enviar, conferir e baixar esses arquivos. O Google não restringe tecnicamente o acesso a essa pasta; a limitação decorre da configuração da rotina.
  • Nenhum outro serviço do Google (como Gmail, Contatos ou Agenda) é acessado.

3. Como os dados são usados

  • Os arquivos de backup são criptografados no computador do responsável antes do envio. No Google Drive, o conteúdo e os nomes desses arquivos ficam criptografados.
  • Os dados do Google Drive são usados somente para guardar e recuperar esses backups.
  • O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

4. Onde ficam as credenciais

As credenciais de acesso emitidas pelo Google ficam somente no computador do responsável, em arquivo de configuração criptografado. O rclone se comunica diretamente com as APIs do Google; não existe servidor intermediário deste aplicativo.

5. Compartilhamento

Os dados obtidos do Google Drive não são vendidos, compartilhados ou transferidos a terceiros e não são usados para publicidade.

6. Revogação e exclusão

  • O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
  • Os arquivos de backup podem ser apagados pelo titular diretamente no Google Drive.

7. Este site

Estas páginas não usam cookies, rastreadores, anúncios nem scripts. Elas são hospedadas pelo GitHub Pages, que pode registrar dados técnicos de acesso conforme a declaração de privacidade do GitHub.

8. Alterações e contato

Alterações nesta política serão publicadas nesta página, com nova data de vigência. Contato: perfil do responsável no GitHub.
